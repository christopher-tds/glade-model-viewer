# Glade Model Viewer

Browse and stage Glade's 3D goggle models (.glb), one at a time.

**Live:** https://christopher-tds.github.io/glade-model-viewer/

- 83 models streamed from Shopify's CDN; only the selected one loads.
- Save camera poses and reuse them across models (S to save, 1–9 to recall).
- Export the current view as PNG (transparent) or JPEG (white).
